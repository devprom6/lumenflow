# Architecture Decision Records (ADRs)

This directory contains the Architecture Decision Records for LumenFlow.

ADRs document significant decisions: what was decided, why, and what alternatives were considered.

## Index

| ADR | Title | Status |
|---|---|---|
| [ADR-0001](./ADR-0001-monorepo-pnpm-turborepo.md) | Monorepo with pnpm + Turborepo | Accepted |

## How to write an ADR

Copy the template below, save it as `ADR-NNNN-short-title.md`, and fill it in.

```markdown
# ADR-NNNN: Title

**Date:** YYYY-MM-DD
**Status:** Proposed / Accepted / Deprecated / Superseded by ADR-XXXX
**Deciders:** names or team

## Context
## Decision
## Alternatives Considered
## Consequences
## References
```
